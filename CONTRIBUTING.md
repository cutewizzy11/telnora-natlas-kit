# Contributing to Telnora N-ATLAS Kit

Thanks for helping make N-ATLAS easier to build with.

## Getting started
1. Fork and clone the repo.
2. `npm install`
3. `npm run dev` and open http://localhost:3000

## Layout
- `packages/sdk` – `@telnora/natlas` TypeScript client
- `packages/react` – `@telnora/natlas-react` chat and voice components
- `app/` – playground and docs (Next.js)

## Pull requests
- Keep PRs small and focused; describe what changed and why.
- Run `npm run build` before opening a PR.
- Open an issue first for large changes.

## Reporting bugs
Open an issue with the endpoint type you use (vLLM, official API, other), steps to reproduce, and the error message.
